# Real3st Shooters Academy BI System

A Business Intelligence and Management System developed for Real3st Shooters Academy.

The system manages students, courses, memberships, payments, certifications, firearms qualifications, users, and business reports while providing an executive dashboard for monitoring academy performance.

## Features

### Student Management
- Add students
- View students
- Edit student information
- Delete students
- Track student records

### Course Management
- Manage academy courses
- Track course categories
- Course pricing
- Monitor course enrollments

### Membership Management
- Manage student memberships
- Track active memberships
- Monitor upcoming membership renewals

### Payments
- Record student payments
- Track payment history
- Calculate total revenue

### Certificates
- Manage student certificates
- Track certification information

### Firearms Qualifications
- Record student firearms qualifications
- Track qualification issue dates
- Assign instructors

### Business Intelligence Dashboard

The dashboard provides important business metrics including:

- Total Students
- Total Courses
- Total Memberships
- Total Payments
- Total Revenue
- Most Popular Course
- Membership Renewals Due
- Students Trained
- Monthly Revenue
- Revenue by Course
- Revenue by Division

The Revenue by Division dashboard compares revenue generated by:

- Firearms
- Security
- Drone

### Reports Center

The reporting module allows administrators and management to:

- Generate reports
- Search report records
- Export reports to Excel
- Print / save reports as PDF
- Refresh live report data

### User Management

The system currently supports two primary roles:

#### Administrator

The Administrator has full system access including:

- Dashboard
- Students
- Courses
- Memberships
- Payments
- Certificates
- Qualifications
- Reports
- User Management

#### CEO

The CEO has executive-level access to:

- Dashboard
- Reports

Operational management modules and User Management are restricted.

## Role-Based Access Control

The application uses role-based permissions.

Users are authenticated through the login system and their role determines which areas of the application they can access.

Restricted pages also perform authorization checks to prevent unauthorized users from accessing them directly through the browser URL.

## Running the Project

### 1. Start PostgreSQL

Make sure the PostgreSQL database server is running.

### 2. Start the Flask Backend

Open the backend folder and run:

python app.py

The API runs locally on:

127.0.0.1:5001

### 3. Start the Frontend

Open the dashboard using VS Code Live Server.

Example:

127.0.0.1:5500/dashboard/login.html

### 4. Login

Use an authorized account created in the users database.

For security reasons, passwords should not be stored in this README or committed to GitHub.

## Security

The system includes basic authentication and role-based authorization.

Production improvements should include:

- Password hashing
- Server-side sessions or JWT authentication
- Environment variables for database credentials
- Backend authorization for protected API routes
- Input validation
- HTTPS
- Audit logging
